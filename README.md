# Toterra 万象之土

A Minecraft mod (closed source) that brings a hyper-realistic, all-domains experience to survival: every field of life is expanded to vast depth, the world is filled with endless variations of creatures and terrain, and each player can only master a few realms.

一个闭源的 Minecraft 模组，为生存带来超现实的万物体验：每个领域都被扩展出深厚内容，生物与世界生成充满无穷变种让探索永无止境，而每位玩家只能精通少数领域。
